# 1310.4546 extensions: do not misattribute to the January 2013 paper

Source: [Distributed Representations of Words and Phrases and their Compositionality](https://arxiv.org/abs/1310.4546) (October 2013).

| Mechanism | Paper | In repository | Experiment |
| --- | --- | --- | --- |
| Subsampling frequent tokens | §2.3 | `data/subsample.py`, `data/dataset.py`; `DATA.subsample_formula` chooses legacy vs 1310 probability | `followup_1310.yaml::subsampling` |
| Negative sampling | §2.2, Eq. (4) | `models/cbow.py`, `models/skipgram.py`, `losses/negative_sampling.py` | `hs_vs_ns`, `negative_count` |
| Unigram distribution exponent | §2.2 | `data/sampler.py`, `MODEL.ns_power` | `negative_exponent` |
| Phrase detection / compositionality | §3 | Not implemented | Separate future phase, not a claim of coverage |

The original code used the retention probability `min(1, sqrt(t/f) + t/f)` for the 2013 extension.
The repository's earlier legacy probability retained `min(1, sqrt(t/f))`; these differ.
New runs can explicitly choose `DATA.subsample_formula: mikolov_1310`, while the existing
`legacy` default remains for compatibility with old checkpoints and configurations.

For negative sampling, the distribution weights are `count ** ns_power`; the original value is 0.75.
The loss draws K negatives for every positive example and excludes the positive ID in this implementation;
that exclusion changes the distribution relative to an unconditional draw and must be reported.
This repository has deterministic, separate random streams, but does not claim exact C implementation equivalence.
