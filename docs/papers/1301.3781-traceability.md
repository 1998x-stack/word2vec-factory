## Critical reproduction qualifications

1. The original paper uses Huffman hierarchical softmax as its word-output approximation. Negative sampling and frequent-word subsampling are explicitly sourced to [1310.4546](https://arxiv.org/abs/1310.4546), not silently labeled original.
2. Original CBOW takes four future + four history words (fixed radius 4); its architecture has no word-order representation. Skip-gram samples R uniformly in [1,C], giving nearby words higher selection probability. Do not use the same random window strategy for CBOW if claiming paper-protocol fidelity.
3. Original Table 3 compares models on ~320M training words and 82K vocabulary with 640-dimensional vectors. Table 2 uses a limited 30K-vocabulary evaluation. Results cannot be numerically compared with the bundled sample corpus.
4. The Google News 6B training tokens, LDC training corpora, original high-core-count DistBelief setup, and MSR sentence-completion dataset are not bundled. Logs distinguish **method reproduction** from **benchmark replication**.
5. The current engine trains with batches and source-token-progress LR, rather than exact single-example SGD per update. Fixed seeds guarantee repeatability only within a controlled software/hardware environment, not cross-device bitwise equality.
6. The existing internal Huffman path IDs map to V-1 trainable nodes, not 2V-1 output tokens. Skip-gram HS targets are the **context** words.
7. Note: earlier README's shorthand "paper-style randomized context windows" is correct for Skip-gram but not sufficient to document CBOW's fixed eight-word original setup.

## Numerical reproduction study: separate staged protocol

- Stage P0: run the bundled smoke suite to validate mechanics, **not** accuracy.
- Stage P1: record external corpus provenance/licensing, tokenizer, raw SHA-256, number of trainable tokens, original corpus partitioning and evaluation overlap.
- Stage P2: run CBOW/Skip-gram + Huffman with fixed seeds and matched 30K (Table 2) or wider (Table 3/4) vocabulary ceilings. Verify input/output direction and fixed CBOW vs random Skip-gram window.
- Stage P3: train three seeds for each comparison and report mean, sample SD, paired effect sizes and bootstrap confidence intervals; do not reinterpret paper's single reported percentages as modern confidence intervals.
- Stage P4: separately design a *two-dimensional* (corpus tokens × embedding dimension) factorial study and a matched-compute study of new-data vs repeated-epoch budgets.
- Stage P5: when comparable raw data and hardware are actually available, report reproduction differences relative to original table values with complete protocol caveats.
